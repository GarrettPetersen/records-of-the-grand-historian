## Repair goals

1. Source correspondence
   - Inspect pending source queue items for this chapter.
   - If upstream Chinese has real text missing from the local chapter, accept it, add faithful `manualTranslations`, and apply it with `scripts/apply-source-correspondence.mjs`.
   - Every `manualTranslations` entry must include `translator: "Garrett M. Petersen (2026)"` and `model: "Composer 2.5"` before applying.
   - When translating newly inserted source text, be especially careful with proper nouns: era names, cyclical days, palace/hall names, office titles, and personal names. Do not guess readings from visual similarity. For example, `元符` is Yuanfu (not Yuanshu), `辛亥` is xinhai (not xinghai), `大慶殿` is Daqing Hall (not Dading Hall), and `韓縝` is Han Zhen (not Han Zong).
   - If the local chapter already has nearby translations of the same reign era, hall, office, or personal name, match the existing spelling and terminology.
   - In biographies, check the immediately surrounding subject's full name before romanizing a single-character reference. If a sentence says `包咸字子良`, later `咸曰` is Bao Xian, not an unrelated person named Xian; `黃讜` is Huang Dang, not Huang Tan.
   - Do not leave Chinese characters in English `literal` or `idiomatic` fields for newly repaired text, and do not add `allowChineseCharacters` to bypass translation. Romanize personal names and translate offices/places into English, matching nearby chapter usage when possible.
   - `allowChineseCharacters` is only appropriate when the Chinese character or written form itself is being referenced and it would not make sense to translate it away; it is not appropriate for untranslated names, offices, places, or ordinary prose.
   - If you add, move, renumber, or otherwise materially repair chapter text for a source queue item, that item is not a no-op: mark it `applied`, not `denied`, and explain what changed.
   - If the upstream difference is a no-op (raw Wikisource markup, table layout residue, source-page boilerplate, harmless graph variant, or an upstream witness defect where local text is fuller/correct), mark only that queue item `denied` with a clear note by using `scripts/mark-source-correspondence.mjs`.
   - Do not hand-edit the large source queue JSON for status/decision/notes changes. Use the helper scripts so the file is parsed and reserialized safely.
   - Never mark an item resolved just to clear the queue. If uncertain, leave it pending and explain why in your final response.

2. Placeholder translations
   - Replace placeholder English with real translations based on the Chinese source.
   - Preserve both `literal` and `idiomatic` fields.
   - Use `translator: "Garrett M. Petersen (2026)"`.
   - If you add or materially rewrite translations, use `model: "Composer 2.5"`.

3. Quote and speech fidelity
   - Where Chinese uses direct quotation punctuation (`「」`, `『』`), English must preserve direct speech with balanced quotation marks.
   - Use standard English double quotation marks for direct Chinese quotation; reserve single quotation marks for nested quotations inside an existing quote.
   - Do not turn direct quotation into indirect paraphrase. For example, do not render `X曰：「Y。」` as `X said that Y`; render it as direct speech.
   - Make the speaker clear when the English sentence needs a speech tag.
   - Keep first-person language inside quoted speech when the Chinese speaker refers to themselves.
   - If Chinese quotation marks enclose a title rather than speech, keep an English title quotation and use normal English punctuation.

4. Opportunistic mistranslation fixes
   - If you notice a clear mistranslation while repairing the queued issues, fix it.
   - Keep edits conservative; do not rewrite correct prose for style alone.
