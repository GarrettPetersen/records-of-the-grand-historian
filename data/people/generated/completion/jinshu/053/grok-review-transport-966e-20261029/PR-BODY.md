GrokBot could only transport extraction work, leaving its separate allowance idle while completed chapters waited for identity and editorial review. This adds sealed downstream review reports through the existing five MCP operations. The host retains ownership, native acceptance, independent review and publication gates.

Signed jobs bind packet, scope and reviewer identity. Dispatch checks actual pending work, the real agent roster, the deployed public client hash and app readiness before reserving a prompt. Sticky extraction remains recoverable; returned reports occupy no execution slot. A client/server version guard prevents an old extraction-only server from treating a review request as fresh extraction.

Validation: 41 offline tests pass, including authenticated HTTP/CLI round trips, tampered input, wrong reviewer, no-work dispatch, original-result preservation and old-server rejection. An independent reviewer approved the implementation; a fixture preview passed against the existing service dependencies and live read-only queue. This PR contains process/code changes and necessary dependencies only, with targeted npm-script edits against master; it does not claim chapter completion.
