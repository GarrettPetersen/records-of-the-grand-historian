## Findings

- V9 fixes the v8 direct-output hazard: the public analysis API returns only `analysisOnly`, unresolved candidate/span diagnostics, a review packet, and summarized mention, claim-evidence and disposition data. It does not return a reconciled extraction. For the pinned Jinshu 127 inputs, it produced 13 questions, and strict `validatePeopleExtraction` rejected the analysis object because required extraction fields were absent and extra fields present. This does not prevent a programmer from intentionally manufacturing a new extraction by other means; it removes the previously demonstrated accidental `result.extraction` serialization path.
- The production reconciliation wrapper explicitly passes false to the internal analysis parameter. On the real fixture, passing `analysisOnly: true` in caller options still failed with `Unscanned name surface requires source review: 13 occurrence(s)`. Repository script call-site inspection found the analysis function used in the CLI self-test and regression tests, not the production reconciliation path. Assertions about fail-closed behavior cover surfaces actually enumerated by this guard, not every possible missed person.
- Unscanned review replay remains disabled: there is no trusted host-dispatch verifier. A report or fingerprint is not approval; the guard still fails closed when unscanned questions are present, and genuine review cannot be replayed through this patch. Existing source-review, independence, identity, date, validation and publication gates remain necessary.
- The supplemental detector is not a complete coverage proof. It searches English preferred names/name claims only within units already associated with the person and suppresses occurrences contained by any mention or scanner candidate regardless of person or disposition. Unknown aliases, Chinese-only occurrences, unassociated units and wrongly covered occurrences can be missed. In the real packet, s0148 `Bi Lü Hun's father Wei` overlaps distinct existing mentions for p079 and p085; it must not become a single automatic link. Several other exported longer surfaces overlap existing shorter mentions. Resolve only with source review and identity-preserving overlap handling.
